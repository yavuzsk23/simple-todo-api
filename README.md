# Simple Todo API

## 🇬🇧 English
A clean and simple REST API for managing tasks, built with **FastAPI** and **SQLModel**.

### Features
- Modern and fast Python backend
- Automatic database table creation
- RESTful endpoints with validation
- Interactive Swagger UI documentation
- Clean, readable and well-documented code

### Tech Stack
- Python 3.10+
- FastAPI
- SQLModel + SQLite
- Uvicorn

### Quick Start

```bash
pip install fastapi sqlmodel uvicorn

uvicorn main:app --reload---
